## 变更 1：日期可以直接点开选日历

**不做新页面。** 主页顶部已经有切换日期的地方，给它的日期加上「点击弹日历」就行。

**现在**：

```
┌────────────────────────────────────┐
│    ‹         10月14日 周三        ›  │
└────────────────────────────────────┘
      只能一天一天往回/往前翻
```

**改后**：

```
┌────────────────────────────────────┐
│    ‹      10月14日 周三  📅      ›  │
│            └── 点这里弹出日历         │
└────────────────────────────────────┘
```

- 点 **‹ / ›** → 前一天 / 后一天（保留现有的）
- 点 **中间的日期（或右边的日历图标）** → 弹出系统日历，直接跳到任意一天

## 变更 2：主页改版 —— 从「按人分」改成「按功能分」

这是这次最大的改动。

**现在的结构**（先分人，再看功能）：

```
┌─ 我 ────────────────────────────┐
│  心情日记   三餐报备   留言提醒   │
└─────────────────────────────────┘
┌─ TA ────────────────────────────┐
│  心情日记   三餐报备   留言提醒   │
└─────────────────────────────────┘
```

**改成**（先看功能，再看人）：

```
┌─ 心情日记 ──────────────────────┐
│  TA    😌 平静   还行吧   09:15  │
│  我    😊 开心   今天很开心 20:30│
└─────────────────────────────────┘

┌─ 三餐报备 ──────────────────────┐
│  TA    [早餐] [午餐] [晚餐] [宵夜]│
│  我    [早餐] [午餐] [晚餐] [宵夜]│
└─────────────────────────────────┘

┌─ 留言提醒 ──────────────────────┐
│        （两个人的留言，见变更 4） │
└─────────────────────────────────┘
```

**为什么这样更好**：你想跟对方比"今天谁吃得更好"、或者看"我们俩今天都什么心情"时，
不用在页面上上下下来回找 —— 同一个功能下两块直接挨着对比。

> ❓ 板块名我沿用了原来的「三餐报备」，你这次写的是「三餐记录」。用哪个？

## 变更 3：给 TA 留言去掉定时提醒

写留言的弹层里，那个「定时提醒」开关 + 日期/时间选择器**全部删掉**。

理由：这个功能**设了不生效**（后端只把时间存进库，没有任何定时任务去读它），留着是骗人的。

改完后只剩一个行为：**立即送达**。（数据库的 `remind_at` 字段保留不用，以后真要做推送时再说。）

## 变更 4：留言提醒改成「双向记录板」，可以点着回复

**现在**：只能看 TA 发给我的（收件箱），我发出去的留言在 App 里**完全看不到**。

**改成**：两个人的留言**合在一个板块里**，像聊天一样按时间排开，你一句我一句。

### 4.1 长这样

```
┌─ 留言提醒 ──────────────────── ● 2 条未读 ┐
│                                          │
│  TA   20:30                              │
│  ┌────────────────────┐                  │
│  │ 记得多喝水          │                  │
│  └────────────────────┘                  │
│                                          │
│                              我   20:35  │
│                  ┌────────────────────┐  │
│                  │ 好，你也是          │  │
│                  └────────────────────┘  │
│                                          │
│  TA   21:00                              │
│  ┌────────────────────┐                  │
│  │ 早点睡              │                  │
│  └────────────────────┘                  │
│                                          │
│  [ ＋ 写留言 ]                            │
└──────────────────────────────────────────┘
```

- TA 发的靠左，我发的靠右
- 未读的留言带高亮标记，滚动到可见位置自动标已读
- 底部「＋ 写留言」发新留言

### 4.2 点某条留言 → 回复

点任意一条留言，弹出输入框，**带引用原文**：

```
┌──────────────────────────────────────────┐
│              回复留言                     │
│  ┌────────────────────────────────────┐  │
│  │ TA 20:30                           │  │
│  │ 记得多喝水                          │  │  ← 引用原文
│  └────────────────────────────────────┘  │
│  ┌────────────────────────────────────┐  │
│  │ 输入回复…                          │  │
│  └────────────────────────────────────┘  │
│         [ 取消 ]      [ 发送 ]           │
└──────────────────────────────────────────┘
```

回复发出去后，在列表里显示成：

```
                              我   20:37  │
                  ┌────────────────────┐  │
                  │ ↳ 记得多喝水        │  │  ← 灰色小字引用
                  │ 好的，这就去喝      │  │
                  └────────────────────┘  │
```

> 这需要在 `messages` 表加一个 `reply_to_id` 字段记录"回复的是哪条"。

### 4.3 ❓ 留言板块跟不跟随顶部日期？

这是**需要你定**的一个点，两种做法差别挺大：

**方案 A：跟随日期**（和心情、三餐一致）
翻到 10 月 1 日，就只看那天两个人的留言。
- ✅ 整页三个板块行为统一，翻历史很直观
- ❌ 聊天被打断成一天一段；翻到过去某天想回一句，发出去后会跳到"今天"，有点割裂

**方案 B：不跟随日期**（留言永远是最近的对话）
留言板块始终显示最近的消息，只有心情和三餐跟着日期走。
- ✅ 符合"聊天"的直觉，随时能接上话
- ❌ 整页里有一块"不听日期指挥"，可能让人困惑

**我倾向 A**（整页行为统一，且你要的就是"按天查看记录"），但这条确实两说，你定。
